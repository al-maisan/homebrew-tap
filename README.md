# al-maisan/homebrew-tap

Homebrew formulae for:

- [gmt-mail](https://github.com/al-maisan/gmt-mail): sends personalized bulk emails (mail merge) from the terminal over SMTP with TLS.

      $ brew install al-maisan/tap/gmt-mail

  The formula builds the tagged release from source. It is bumped for every gmt-mail release (see the gmt-mail README, "Releasing a new version").

- [node-tracker](https://github.com/al-maisan/node-tracker): alerts you on Telegram when your Bitcoin node falls behind the chain tip, and when it catches up.

      $ brew install al-maisan/tap/node-tracker

  The formula installs the signed release binaries (macOS and Linux, amd64 and arm64). `make release` in node-tracker writes it for every stable release (see its CONTRIBUTING.md, "Releasing").
