# al-maisan/homebrew-tap

Homebrew formulae for [gmt-mail](https://github.com/al-maisan/gmt-mail), which sends personalized bulk emails (mail merge) from the terminal over SMTP with TLS.

    $ brew install al-maisan/tap/gmt-mail

The formula builds the tagged release from source. It is bumped for every gmt-mail release (see the gmt-mail README, "Releasing a new version").
